# Blast to Bog

Does the blast design decide how many automated loaders one operator can run?

Open the page: https://puneethabhishek-glitch.github.io/blast-to-bog-page/

A browser simulation of one production level where one operator fills each bucket by remote control and the loaders drive, dump and return on their own. Every input is labelled as verified, calibrated or assumed, and every assumed value can be changed on the page.
